##  Mini Project

### Retail Sales Analytics

The final mini project implements an end-to-end data engineering and business intelligence solution using retail sales data.

The project includes:

- Data ingestion
- Data profiling and quality assessment
- Data cleaning
- Data transformation
- Star Schema data warehouse
- Fact and dimension tables
- Data validation
- Power BI data modeling
- DAX calculations
- Interactive dashboard

### Project Components

- **Python Notebook** – ETL, cleaning, transformation, and warehouse preparation
- **CSV Files** – Raw, transformed, fact, and dimension datasets
- **Power BI Dashboard** – Interactive business intelligence reporting
- **Dashboard Screenshot** – Preview of the final dashboard
